## Funções

Uma **função** é uma relação entre dois conjuntos em que **cada elemento do domínio** está associado a **um único elemento do contradomínio**.

Em outras palavras, para cada valor de entrada existe **apenas uma saída**.

### Definição

Seja \(f\) uma função de um conjunto \(A\) em um conjunto \(B\). Escrevemos:

\[ f: A \to B \]

Isso significa que:

- \(A\) é o **domínio**;
- \(B\) é o **contradomínio**;
- para todo \(x \in A\), existe exatamente um valor \(f(x) \in B\).

Se algum elemento do domínio tiver mais de uma imagem, ou não tiver imagem, a relação **não é função**.

### Domínio

O **domínio** é o conjunto de todos os valores que podem ser usados como entrada da função.

Exemplo: se \(f(x) = x + 2\), o domínio pode ser todos os números reais, desde que não exista nenhuma restrição na expressão.

### Contradomínio

O **contradomínio** é o conjunto que contém todos os possíveis valores de saída informados na definição da função.

Ele não é necessariamente igual ao conjunto de valores que realmente aparecem como resultado.

### Imagem

A **imagem** é o conjunto dos valores que a função realmente assume ao aplicar todos os elementos do domínio.

Exemplo: se \(f(x) = x^2\) com domínio nos reais, a imagem é \([0, +\infty)\), pois o quadrado de qualquer número real nunca é negativo.

### Exemplos de leitura

- \(f(2) = 5\): quando a entrada é 2, a saída é 5.
- \(f(x) = 3x\): a regra da função é multiplicar a entrada por 3.
- \(y = f(x)\): a variável \(y\) representa o valor da função para cada \(x\).

### Interpretação de gráficos

No gráfico de uma função:

- o eixo horizontal representa o **domínio**;
- o eixo vertical representa os valores da **imagem**;
- para cada valor de \(x\), deve existir no máximo um valor de \(y\).

Um teste visual importante é a **reta vertical**: se uma reta vertical cortar o gráfico em mais de um ponto, a relação não representa uma função.

### Exercícios (para identificar se uma relação é ou não uma função)

1. \(\{(1,2), (2,3), (3,4)\}\)
2. \(\{(1,2), (1,5), (2,3)\}\)
3. Tabela com entradas 0, 1 e 2, associadas respectivamente a 4, 5 e 6.
4. Gráfico que passa no teste da reta vertical.
5. Relação em que um mesmo valor de entrada produz duas saídas diferentes.

**Resposta esperada:** os itens 1, 3 e 4 representam funções; os itens 2 e 5 não representam funções.
