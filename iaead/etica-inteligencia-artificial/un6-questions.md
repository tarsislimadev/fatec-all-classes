# Ética na Inteligência Artificial

## Unidade 6

### Perguntas Avaliativas

Pergunta: Praticamente nada do que consumimos existe por si só, assim tudo que consumimos teve a necessidade de interação com outras pessoas para que ficassem disponíveis para nós. Dessa maneira podemos afirmar que o consumo é:

Resposta: Mais do que uma compra, mas sim uma interação social.

Pergunta: Os ataques em massa caracterizam os Hacktivistas. Um ataque bem conhecido de hacktivistas é a rede 911 S5 que atacou entre 2014 e julho de 2022, atingindo por volta de 19 milhões de endereços IP. O que são os hacktivistas?

Resposta: Hacktivistas são hackers que utilizam de ataques cibernéticos para promover ideologias políticas.

Pergunta: Os dispositivos informáticos foram desenvolvidos para nos ajudar a realizar afazeres de forma mais eficaz e rápida, com maior assertividade. O que são os dispositivos informáticos? Os dispositivos informáticos são produtos eletrônicos que tem como função realizar tarefas específicas como armazenamento de dados, processamento de informações, controle de outros dispositivos e transmissão de sinais. Os dispositivos informáticos são produtos de informática como mochilas para computadores, baterias e extensões de energia. Os dispositivos de informática são componentes eletrônicos providos de funções em sistemas eletrônicos. 

Resposta: Somente as afirmações I e III estão corretas.

Pergunta: Os hacktivistas normalmente utilizam os botnets como ferramenta para estruturar ataques virtuais em massa, derrubando servidores, roubando dados e distribuindo malware (software malicioso). O que são os botnets?

Resposta: Os botnets são redes de dispositivos de computador que servem para automatizar grandes ataques. Os botnets são redes de dispositivos de computador gerenciadas remotamente; isso pode ocorrer em milhares ou até milhões de máquinas, chamadas máquinas zumbis. Os botnets são redes de dispositivos de computador que infectam várias máquinas e essas ficam sob o comando de um grupo malicioso. Os botnets são redes de dispositivos de computador controladas por hackers, esses comandam as máquinas infectadas por meio dessa rede que eles mesmos constroem. Todas as anteriores estão corretas.
