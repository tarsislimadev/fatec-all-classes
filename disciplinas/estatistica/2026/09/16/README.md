# Encontro 2026/09/16 - Estatística

## Média de dados discretos em tabelas

Para calcular a média, multiplica-se cada valor (`xᵢ`) pela sua frequência (`fᵢ`), soma-se o resultado e divide-se pela soma das frequências:

`x̄ = Σ(xᵢ · fᵢ) / Σfᵢ`

## Média de dados contínuos em tabelas

Para calcular a média de dados contínuos agrupados em classes, calcula-se o ponto médio (`xᵢ`) de cada intervalo, multiplica-se esse valor pela frequência (`fᵢ`) da classe, soma-se os produtos e divide-se pela soma das frequências:

`x̄ = Σ(xᵢ · fᵢ) / Σfᵢ`

O ponto médio de cada intervalo é obtido pela fórmula:

`xᵢ = (limite inferior + limite superior) / 2`
