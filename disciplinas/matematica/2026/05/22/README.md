## Inequações

Nesta aula, o conteúdo deve explicar o conceito de inequações, mostrando como identificar, resolver e interpretar os resultados.

### Pontos principais

- o que é uma inequação;
- diferença entre equação e inequação;
- regras para resolver inequações;
- casos com números negativos e inversão do sinal;
- interpretação da solução na reta numérica.

### Exemplo

Se uma inequação tiver a forma `2x + 3 > 7`, isola-se a variável para encontrar o conjunto solução.
