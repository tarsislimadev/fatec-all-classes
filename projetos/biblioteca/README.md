# projeto biblioteca autonoma

O aluno se identifica para emprestar livros sem a necessidade de autorização do bibliotecário.

## 

O aluno, com smartphone, le QRCode na porta da biblioteca para regitrar sua entrada.

O aluno, com smartphone, le QRCode na capa do livro para regitrar empréstimo (ou sua devolução).

O aluno, com smartphone, le QRCode na porta da biblioteca para regitrar sua saída.
