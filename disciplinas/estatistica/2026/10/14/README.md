## Coeficiente de Variação

O **coeficiente de variação (CV)** é uma medida de dispersão relativa. Ele indica o tamanho do desvio-padrão em relação à média e é útil para comparar a variabilidade de conjuntos de dados com médias ou unidades de medida diferentes.

### Fórmula

Para uma população:

$$
CV = \frac{\sigma}{\mu} \times 100\%
$$

Para uma amostra:

$$
CV = \frac{s}{\bar{x}} \times 100\%
$$

Em que:

- $\sigma$ é o desvio-padrão populacional;
- $s$ é o desvio-padrão amostral;
- $\mu$ é a média populacional;
- $\bar{x}$ é a média amostral.

### Interpretação

Quanto menor o CV, mais homogêneos são os dados em relação à média. Quanto maior o CV, maior é a dispersão relativa.

Por exemplo, se a média de um conjunto é $80$ e o desvio-padrão é $8$:

$$
CV = \frac{8}{80} \times 100\% = 10\%
$$

Isso significa que o desvio-padrão corresponde a 10% da média.

O coeficiente de variação não deve ser usado quando a média é igual ou muito próxima de zero, pois o resultado pode ficar indefinido ou excessivamente distorcido.
