# Banco de Dados Não Relacional

## Unidade 8 - Perguntas Avaliativas

Pergunta: Um aluno em estágio supervisionado foi designado para configurar backup em uma instância de Banco de Dados no MongoDB Atlas. Qual recurso o MongoDB Atlas oferece para gerenciamento de backup?

Resposta: Snapshots automatizadas e políticas configuráveis de retenção.

Pergunta: Após uma falha no sistema, o DBA executa um comando para restaurar um backup feito anteriormente com mongodump. Qual comando deve ser utilizado para restaurar o backup criado?

Resposta: mongorestore

Pergunta: Uma startup que utiliza MongoDB está definindo sua política de backups. A equipe precisa decidir com que frequência os backups devem ser realizados. Qual o critério mais adequado para definir a frequência dos backups?

Resposta: A criticidade das informações e a frequência de atualização dos dados.

Pergunta: Uma empresa de e-commerce deseja garantir a integridade de seus dados em produção. O DBA propõe adotar uma política de backups frequentes. Qual a melhor prática de backup para ambientes produtivos com alta disponibilidade?

Resposta: Realizar backups regulares, armazená-los em local seguro e testar periodicamente a restauração.
